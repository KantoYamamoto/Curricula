# 要件と現在の範囲

確認日：2026-10-11。現在の実装、内容整備の進捗、将来の検討を分けて記載します。詳細な交換形式は[契約0.2.0](exchange-contract-0.2.md)、作業の順序は[工程](milestones.md)を参照してください。

## 目的と対象

学習指導要領の要求、学ぶ対象、学習目標を結び、個人の自学や開発者・AIによるデータ利用を支える基盤を目指します。小中高校から大学教養までを長期対象としますが、現在の全範囲収録は普通教育の小学校・中学校の原文です。

原文収録を先に揃え、その後に学ぶ対象・目標・自然言語の判定観点を順に整理します。原典項目に「目標」という見出しがあることと、独自の学習目標を整理したことは区別します。

## 現在使えるもの

| 領域 | 実装・内容の範囲 |
|---|---|
| 原文 | 小中5,939項目、138区切りの収録が完了。対象資料と除外範囲は[収録仕様](curriculum-coverage.md)に記載 |
| 目標整理 | 小学校国語1・2年「読むこと」の6対象・6目標・6注釈。学年帯全体は整理中 |
| 構造 | 専用の学年・教科属性、版固定の根拠、目標と判定注釈、UUIDと改訂、分割・統合記録、AND/OR前提 |
| 閲覧 | 原文・目標を読む画面、構造画面、収録状況、ローカル読み取りAPI |
| 編集 | SQLiteに下書き保存、新規対象・目標、本文・条件・注釈・原文根拠の編集、確認、新しい版と進捗記録 |
| 教材試作 | 4単元・14問。選択・数値・順序の答え合わせ、記述の解答例と観点 |

教材・問題の安定した交換契約とAPI、インターネットへのサイト・API配信、共同編集の認証・権限、学習履歴・習熟度・推薦は未実装です。教材試作のJSONとAPIは独立した試験形式です。

## 根拠と確認の扱い

説明や対応の根拠は学習指導要領を優先し、記載がない場合は文科省解説や信頼できる学術資料を探します。初等教育の自明な概念に一律の引用は要求しません。独自の文章、引用、練習用の架空資料を区別し、適用条件を残します。

構造検証の成功から目標の達成を推論しません。機械で判定できない目標も保持し、判定に役立つ観点は自然言語の注釈として記録します。確認記録は対象版・範囲・観点・結果を持ち、後の内容変更に自動で流用しません。

## 公開範囲と未決事項

パブリックリポジトリは作成済みです。外部から利用するWebサイト・APIの初回公開範囲、優先する利用者、公開の完了条件は[Issue #2](https://github.com/KantoYamamoto/Curricula/issues/2)で決定を待っています。

小中の原文と整理済み目標を提供し、教材は代表単元に限る案、データ再利用を先行する案、一つの教科・学年で連続した教材を整える案があります。いずれも推奨案で、採用済みではありません。教材・問題モデル、安定API、運用、ライセンスの未決事項は[工程と関連Issue](milestones.md)で追跡します。

## 変更時の完了条件

変更の対象版と範囲を明示し、原文・独自編集・教材の責務を保ちます。参照切れ、型違反、古い改訂への未確認の根拠、解決不能な必須前提を検出し、変更後の利用例を確認します。旧版を再現できること、目標整理の未確認範囲が分かること、仕様と操作手順が実装に一致することを完了条件とします。

初期の比例に限定した要件と工程は[保存版](history/design-2026-09-28/requirements.md)に残しています。
