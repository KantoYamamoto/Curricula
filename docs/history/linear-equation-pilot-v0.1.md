## 3. 能力の下書き

| 仮ID | 能力候補 | 原典対応案 | 達成を確かめる例／レビュー事項 |
|---|---|---|---|
| cp.explain-equation | 方程式と未知数・解の意味を例で説明する | 1100000の項目に部分対応 | 単なる用語暗記と何を区別するか。方程式の必要性は別の能力に分けるか |
| cp.check-solution | 候補値を代入して解かどうか確かめる | 1100000 / 1200000の項目への対応候補 | `3x+5=20`で5と6を区別し、理由を述べられるか |
| cp.solve-basic | 整数係数の基本的な一元一次方程式を解く | 1200000の項目に部分対応 | `3x+5=20`で解を求める。括弧・小数・分数・両辺の文字を含める範囲は未定 |
| cp.explain-transformation | 等式の性質を使って解法の各操作を説明する | 2100000の項目に部分対応 | 両辺から同じ数を引く等の理由を説明できるか。考察する活動も表現できているか |
| cp.formulate | 具体的な数量関係から方程式を立てる | 2200000の項目に部分対応 | 何を未知数にしたか、等式が何を表すかを説明する |
| cp.interpret | 求めた解を元の場面に戻して妥当性を確かめる | 2200000の項目に部分対応 | 数学的な解が場面の条件を満たすかを確認する |

上記の短縮表記は先頭が共通する公式コードの末尾。実装では必ず完全なコードを保持する。これらの能力名・粒度はレビュー対象であり、学習評価問題の実装要求ではない。

## 4. 関係の下書きと反例

| 関係案 | 意味 | 現時点の根拠・扱い |
|---|---|---|
| 一元一次方程式 → 方程式 | より限定した種類である | 独自モデル上の知識関係案。専門家確認待ち |
| 等式の性質による変形 → 等式の性質 | 手続きがその性質を利用する | KnowledgeRelationの候補。学習前提とは別 |
| 基本的な式計算の能力 → cp.solve-basic | 指定した代数的解法の前提 | 条件付きの編集仮説。小学校算数までの前提整備に含める候補 |
| cp.solve-basic → cp.interpret | 解を求めてから場面で解釈する経路 | 全経路で必須とは断定しない。解が与えられれば解釈だけを行える反例がある |

この反例により、「一般的な前提」と「活動中の手順」を同じ辺で表すと誤解が生じることが分かる。関係を増やす前に、対象の文脈と意味を決める。

## 5. 実装に先立って固定したい照合例

1. `cp.solve-basic`から対象の知識と原典コードを取り出せる。
2. 原典の「活用」項目から複数の能力候補が得られる。
3. 部分対応しかない場合、原典の要求を完全にカバーしたと表示しない。
4. 項目ラベルの修正後もID参照が維持される。
5. 未レビューの前提関係が、確定した必須前提として扱われない。
6. 同一対象に「解く」「説明する」という異なる能力が存在できる。
7. 原典の階層、知識の種類の関係、学習前提を区別して出力できる。
8. 単元外に未整備部分があることがデータから分かる。

期待する出力例は[当時の実装引き継ぎ](design-2026-09-28/implementation-brief.md)のタスクT01で具体化する。

## 6. 小学校算数までの前提整備

ユーザーの指定を受け、単元外の前提を後回しにせずMVPに含める。以下は探索の出発点であり、依存関係が確定した一覧ではない。学年・公式コード・関係の強さは原典と専門家レビューで決める。

| 調べる範囲の候補 | 一次方程式との接続を検討する観点 |
|---|---|
| 数の意味、整数・小数・分数の表し方 | 係数・解としてどの数を扱うか |
| 四則計算と逆算 | 等式の操作や計算を支える能力の分解 |
| 等号、数量関係と式 | 等しさの理解と関係を式にする行動 |
| 未知の数量を記号で表すこと | 文字を使った表現への接続 |
| 文章から数量関係を読み取ること | 立式と場面の解釈への接続 |
| 中学校の正負の数と文字式 | 小学校の算数と一次方程式をつなぐ中間の能力 |

調査・収録の進め方案:

1. 一次方程式の各能力について、採用する解法・条件の下で必要な前提を挙げる。
2. その前提を小学校の原典項目までたどり、別の能力として記述する。
3. 各関係に根拠・適用条件・未確認事項を記し、代替経路がある場合は併記する。
4. 小学校算数として取り扱う基礎まで到達したか、今回の対象外か、未調査かを分ける。
5. 「これ以上前提がない」という主張と、「今回ここまで調べた」という境界を区別する。

小学校算数の全領域を収録する解釈ではない。単元内で分数係数等を扱うかによって前提の対象範囲も変わるため、Q04とQ12を併せて決める。
