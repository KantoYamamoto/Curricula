# MVP単元の選定と小標本 v0.3

> 2026-09-28追記：現在の検証対象は[実原典の8教科・11例](../../cross-subject-validation.md)。比例の選定・工程は初期計画の履歴として残す。最新の実施結果は[検証記録](../../reviews/structure-samples.md)を参照。

更新日: 2026-09-28 / 状態: 初期選定・段階的レビュー前

ユーザーは一次方程式を必須にせず、MVPの検証目的に適した範囲の選定を委任した。本資料はその設計判断であり、変更可能。

## 1. 選定

**小6〜中1の「比例の意味と表・式・グラフの対応」を中心にする。** 正の数量を中心とした例から、負の値や座標を含む例までを小さく扱い、その解法に必要な前提を小学校算数へたどる。

| 候補 | 検証できること | 初期負担・限界 | 判断 |
|---|---|---|---|
| 正負の数の基本計算 | 数の範囲、手続きと能力 | 小規模だが、複数表現・同一対象の学び直しの検証が弱い | 前提として含める |
| 一元一次方程式 | 意味、解法、説明、活用 | 文章題や解法を広げると能力と前提が増える | 旧候補として保存 |
| 比例の表・式・グラフ | 小中の対応、複数表現、条件の異なる能力、部分対応 | 構造表示と章節に沿った閲覧を同じデータで検証できる | 初期選定 |
| 平均・データの比較 | 文理横断、解釈、不確実性 | 調査設計や統計的推論まで広げると初期の意味付けが難しい | 高校・大学への検証例候補 |

この評価は工数実測や学習効果の比較結果ではなく、今回のモデル検証目的に対する設計判断。

## 2. 収録範囲

含める: 比例の対象・性質、表・式・グラフの関係、数量や座標の条件、説明・表現・利用の能力、関連する小学校算数の前提、原典との部分対応。

初期に網羅しない: 反比例全体、比例式の解法、一次方程式単元全体、一次関数全体、複雑な文章題、インタラクティブなグラフ教材、全学年の全前提。

`y=2x+1`などは比例でないことを区別する反例として使用できる。有限個の表の値だけから、すべての値について比例すると証明した扱いにしない。比例という条件が与えられている例と、観測から仮説を立てる例を区別する。

## 4. 能力と表現の小標本案

仮IDは公開契約ではない。すべてAI下書き・未レビュー。

| 仮ID | 能力案 | 条件・達成例 |
|---|---|---|
| cp.read-proportion-table | 比例する二量の表から対応する値を読む | 与えられた比例関係、正の数量。値と単位を取り違えない |
| cp.explain-proportion | 比例の関係を数量の変化で説明する | 「一方が2倍なら他方も2倍」等を条件付きで説明 |
| cp.make-proportion-table | 比例の式から表を作る | 与えられた係数と入力の範囲を使う |
| cp.link-positive-representations | 正の数量の比例を表・式・グラフで関連付ける | 文脈が許す定義域と単位を保持 |
| cp.link-signed-representations | 負の値も含む比例を表・式・座標で関連付ける | 負の係数、負の入力、0を含む例を区別 |
| cp.explain-nonexample | 比例しない関係を反例で説明する | 与えられた規則の比較。標本が少ないだけの不確実性とは区別 |
| cp.apply-proportion | 比例とみなす条件を確認し、数量を求める | 例: 一定の単価という条件。現象に比例を無条件適用しない |

共通の対象候補は「比例関係」「対応する量」「比例定数」「座標」「表現形式」。特定の式や表の例、教材ファイルは共通概念と別に扱う。x=0でy/xを計算する等の不正な条件を具体例で検出する。

## 5. 小学校までの前提のたどり方

探索候補: 数と四則計算、倍と等分、対応する数量、式、表の読み取り、グラフの目盛り。中学校の負の数・文字式・座標は符号を含む例の前提候補。単元の掲載順だけを根拠に、これらすべてを必須としない。

能力ごとに採用経路を選び、前提を原典項目と対応付ける。「算数の基礎としてここまで整備」「今回の経路では不要」「未調査」を分ける。認知発達や一般的な言語能力まで無制限に展開しない。

前提が想定より広がったら、未調査を隠して完了にせず、まず正の数量の例を通す→符号を含む例を追加する二段階に分ける。停止条件と対象を変更記録に残す。

## 6. 構造の検証と切替条件

この小標本で確認すること:

- 一つの対象を小中の複数項目に対応付ける。
- 同じ対象に対する条件の異なる能力を分ける。
- 原典の一部だけを扱った場合に完全対応としない。
- 表現形式・具体例・教材を混同しない。
- 小学校からの前提経路と原典の階層を区別する。

高校・大学での再利用、機関差、立場の違いは[別の構造検証例](architecture-cases.md)で確認する。MVPを大学までの巨大な教材列にはしない。

切替条件: 前提整備が構造検証を圧迫する、資料調査や段階的レビューで能力粒度が不適切と分かる、比例では重要なモデル上の違いを検証できない場合。旧案は[一次方程式の検討履歴](../linear-equation-pilot-v0.1.md)として残す。

## 7. 初期の停止条件と閲覧範囲（v0.3）

範囲選定を委任された上での作業上の境界。調査で不適切と分かれば理由を記録して変える。

- 本体は上記7能力案を出発点に、正の数量、符号と座標、簡単な適用条件まで。細分化・統合は実例に従う。
- 前提は、整数・簡単な小数や分数の乗除、倍と等分、値の代入、表の対応・目盛り、正負の数、座標のうち、採用する例に必要なものを整備する。
- 数の読み書き、基本的な加減、単位の読み取り等へ到達した箇所は、対応する原典と説明を持つ基礎項目として記録し、それ以上の認知的・言語的要素への分解を初期範囲から外す。数学的に前提が存在しないという意味ではない。
- 前提項目も指導要領対応を確認するが、全項目について独立した教材章や多数の例題を作らない。未調査は境界到達と区別する。
- 学習指導要領・知識・能力を読むページを作る。章立てと表示内容は[閲覧・API仕様](viewer-api.md)を参照。
