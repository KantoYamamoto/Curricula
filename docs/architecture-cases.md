# 構造検証の境界例

確認日：2026-10-11。A01〜A14は初期設計から追跡する検証観点です。実原典の[8教科11例](cross-subject-validation.md)と、意図的に条件を変えた[補助標本](sample-catalog.md)を併用します。標本に限った構造の確認で、全分野の内容整理完了を示しません。

大学・架空課程の例は合成データであり、特定の大学の到達目標の引用ではありません。

| ID | 境界例 | 期待する振る舞い |
|---|---|---|
| A01 | 同じ対象が小6と中1に現れる | 対象を強制複製せず、原典・目標・教育属性を区別 |
| A02 | 正の数量の表と負の座標のグラフ | 同じ対象でも条件と目標を区別 |
| A03 | 比例、一次関数、線形写像 | 名称の近さで統合せず、定義と条件を保持 |
| A04 | 架空大学A/Bの年度・課程 | 機関・年度を区別。架空の学年・文科省コードを要求しない |
| A05 | 機関別の履修順と学習経路 | 履修規則を普遍的な前提に変換しない |
| A06 | 参照基準、シラバス、書籍 | 資料種別・書誌・由来・適用範囲を保持。非告示資料に告示日を要求しない |
| A07 | 同じ用語の異なる定義 | 条件が違えば別IDとし、同値と自動判定しない |
| A08 | 科学モデルの近似と数学の成立条件 | 条件を残し、無条件の主張にしない |
| A09 | 複数の歴史解釈と根拠 | 異なる立場を併記できる。具体的な史料・批判の収録は別途必要 |
| A10 | 相手・目的に応じた言語活動 | 単一の正解文字列や自動採点を要求しない |
| A11 | 広い態度目標と部分的な対応 | 原文の目標と未収録範囲を保持し、架空の合格条件を作らない |
| A12 | 原典項目の分割 | 旧版を保持し、変更理由と後継を追跡 |
| A13 | 必須・推奨・AND/ORの別経路 | 文脈を保持し、ORを複数の必須辺に変換しない。別経路で解決可能な循環を許す |
| A14 | 外部コードの変更と定義の変更 | コードだけでは対象IDを変えず、意味の変更は改訂・新対象と変更記録で扱う |

A03では実数上の `f(x)=ax` と、`b≠0` の `f(x)=ax+b` を同じ線形写像として統合しません。定義の根拠は[参照資料](cross-subject-validation.md#根拠の扱い)にあります。

## 契約ごとの確認

旧0.1.0の `examples` にはA06の資料メタデータ、A12/A14の正式な変更記録、A13のAND/ORがありません。未対応入力を拒否するテストは旧契約の互換性を確認するため残します。

現0.2.0は資料種別、`changes` と後継一覧、AND/OR式を実装し、`editing-0.2.0`〜`editing-0.2.3` で書き戻しと参照を確認します。A09の具体的な歴史資料の整備、大学のコース・単位管理、一般的な定理証明や目標達成の自動判定は実装していません。

確認時は、入力・対象契約・期待結果を示し、正常例だけでなく参照切れ・型違反・古い改訂・解決不能な経路を検出します。詳しい参照IDとテストは[標本カタログ](sample-catalog.md)を参照してください。
