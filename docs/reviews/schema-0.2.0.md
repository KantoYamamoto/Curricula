# スキーマ0.2.0の実装・検証記録

2026-09-29。学年・教科、根拠、目標と判定注釈、IDと編集履歴、前提経路、出典種類の変更を実装した。

## 完了した変更

- 学校段階、学年帯、未指定／非該当、教科・科目を専用属性化し、APIと画面で検索可能にした。
- 対象と編集版をUUIDで識別し、別名・外部コードは別の索引にした。明示的な発行スクリプトと登録簿で再出力時のID変更を防ぐ。
- 根拠を対象のフィールドと出典の版・箇所に結び付けた。原文・記述・条件・観点・対応範囲を128件の根拠レコードで保持する。
- 目標と判定注釈を分離。旧13観点を13注釈へ移し、道徳の態度目標を注釈なしでも保持する。教科横断版は90要素、14対応。
- 資料種別と書誌・告示・取得情報を分離。URLや告示日のないシラバス・参照基準・書籍を表現できる。
- 文脈別のallOf/anyOf前提式を実装。代替経路がある循環と、全経路が循環する到達不能を区別する。
- 楽観的競合検出付きの編集操作と、分割・統合の変更記録、旧IDの廃止・後継、旧版参照を実装。

## 自動確認

`make check` 成功。Swift 43件、Python 25件の計68件。独立したPythonによる交換契約確認、既存4版と新5版の正規化JSON再出力一致を含む。`node --check web/app.js` も成功。

主要な否定例は、範囲外の学年、別教科の科目、古い編集版への根拠参照、原典項目と引用位置の不一致、存在しないフィールド、未登録の自動判定器、合成資料の架空取得記録、AND/ORの不正構造、到達不能な前提、競合する編集、同じ編集版での内容変更。これらを拒否する。

編集と同時に注釈・根拠を明示的に更新する正例も確認した。旧4版はGit上でバイト差分がない。

## 画面で確認したこと

- 初期表示がcross-subject-0.2.0となり、11節の原文・学年・教科・目標・注釈を表示。
- 小学校3年・国語の検索で、小3〜4の項目を取得。小1〜2の目標は結果に含まれない。
- 目標詳細で記述・条件・注釈の根拠を個別に表示し、原典項目と出典の版・箇所へたどれる。
- Aまたは(BかつC)を「いずれか必要」「すべて必要」の入れ子で表示。
- 統合後の目標から二つの旧版の目標へのリンクを表示し、旧版の「資料を読む」を再現。
- 道徳の目標が注釈なしで残り、判定方法・採点器を要求しない。
- データ版切替で対象ID・条件をリセットし、旧契約との混在を防ぐ。
