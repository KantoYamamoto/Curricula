# 小標本の範囲と選定目的

確認日：2026-10-11。小標本は構造の確認用で、今後の収録を比例に限定する方針ではありません。全範囲の原文収録と目標整理は[収録台帳](curriculum-coverage.md)で別に追跡します。

## 標本を分ける理由

| 標本 | 選定目的 | 参照 |
|---|---|---|
| `pilot-0.1.0` | 一つの例をモデル→JSON→API→画面まで通す。比例と表・式・グラフ、部分対応を確認 | [初回レビュー](reviews/pilot-0.1.0.md) |
| `cross-subject-0.2.0` | 教科をまたいで学年帯、実験条件、複数観点、資料に基づく説明、態度目標を表せるか確認 | [教科横断の検証](cross-subject-validation.md) |
| `examples-0.1.0` / `examples-0.2.0` | 旧契約で機関・定義・経路・改訂の境界と未対応入力を確認 | [補助カタログ](sample-catalog.md) |
| `editing-0.2.0`〜`editing-0.2.3` | 現契約でUUID維持、分割・統合、AND/OR、複数種類の資料を確認 | [IDと編集操作](identity-editing.md) |
| 教材4単元 | 説明・資料・問題・解答例・観点を、原文や目標とは別に使う体験を確認 | [教材試作](learning-preview.md) |

教科横断標本は国語・理科・社会・外国語・音楽・道徳・算数・情報の8教科11例です。中学歴史や高校情報の履修年未指定、道徳の観点なしの目標も含め、数学の一意な正解や固定学年を全教科へ要求しません。

大学・架空課程の例は構造検証用の合成データであり、実在大学の到達目標の引用ではありません。高校情報の実原典標本があることも、高校全範囲の収録完了を意味しません。

## 追加する標本の選び方

既存の例と異なる構造上の条件を優先します。学年帯、複数資料の根拠、広い目標、記述による判断、複数の前提経路、原典の改訂などについて、入力と期待する振る舞いを先に示します。表現できない場合は欠けた概念を記録し、ダミーの属性や自由文で検証済みにしません。

原典の本文と条件は学習指導要領で確認し、必要なら公式解説や信頼できる資料で補います。練習用の架空資料はその目的が分かるようにします。初等教育の自明な概念に一律の出典を要求しません。

[Issue #2の採用決定](https://github.com/KantoYamamoto/Curricula/issues/2#issuecomment-6099157264)により、初回外部公開は既存4単元の試作を提供します。中学校教材や連続教材の追加は初回の必須条件にせず、後の代表例は確認したい点を示して選びます。代表例の追加と、教科・学年全体の目標整理の完了は別に扱います。

比例を最初に選んだ理由と当時の停止条件は[初期選定の保存版](history/design-2026-09-28/pilot-scope.md)に残しています。
