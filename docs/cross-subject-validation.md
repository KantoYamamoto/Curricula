# 学習指導要領を使った教科横断の構造検証

確認日：2026-10-11。実際の指導要領から8教科・11例、親見出しを含む69項目を選び、教科による要求の違いを確認します。現在の標本は `cross-subject-0.2.0`、旧0.1.0版も保持します。標本と全範囲の目標整理は別の進捗です。

## 原典と再現

文部科学省の[学習指導要領コード表](https://www.mext.go.jp/a_menu/other/data_00001.htm)に掲載された小学校82V12、中学校83V11、高校84V10を2026-09-28に取得した。[現行学習指導要領の案内](https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm)も確認した。CSVのURL・版・取得日・全体のSHA-256と、抽出行の位置をデータ内に保持する。

- [選定表](../Sources/CurriculaPilot/Resources/cross-subject-selection.json)：教科、例、細目コード、明示的な親子経路。
- [固定した原典入力](../Sources/CurriculaPilot/Resources/cross-subjects.json)：CSVの原文そのまま。全角文字、改行、大文字を含む外部コードも保持。
- [旧版の編集記述](../Sources/CurriculaPilot/CrossSubjectSamples.swift)と[0.2.0の編集用選定表](../Sources/CurriculaPilot/Resources/v2-authoring.json)：対象、目標、条件、判定注釈、教育属性、構造化した根拠。
- [現契約の公開JSON](../data/releases/cross-subject-0.2.0.json)：69原典項目＋9対象＋12目標＝90要素、13注釈、128根拠、14対応、11文脈、11節。道徳も独立した目標として保持。
- [旧契約の公開JSON](../data/releases/cross-subject-0.1.0.json)：89要素、13対応。旧版の内容は変更しない。

再取得は `python3 scripts/import_cross_subjects.py --retrieved-on YYYY-MM-DD --output /tmp/cross-candidate.json`。既存ファイルへ上書きせず候補を作り、配布版・ハッシュ・行・階層の差分を確認する。通常のビルド・テストはネット接続なしで固定入力から再現する。

## 見つかった課題と現在の対応

| 課題 | 現在の対応・残る境界 |
|---|---|
| 原典階層をコードの前方一致で復元できない | 選定表で明示的な親子経路を保持。全原文の取り込みではLODの階層を使い、公式PDFと照合・補正 |
| 細目だけでは親の条件が欠ける | 理科の条件制御、音楽の表現意図を親原文へのフィールド別根拠として保持。親の条件の自動継承は未実装 |
| 学年帯が文章だけでは検索できない | 0.2.0の専用 `education` で学校段階・学年集合・教科・科目を保持 |
| 条件・観点の根拠が文章内のコード参照だけ | `evidence` で対象フィールド・原典文書・引用位置・項目を改訂へ固定 |
| 全目標を自動判定に落とせない | 目標と自然言語注釈を分離。道徳の広い目標は観点なしでも保持 |
| 資料種別、改訂、AND/ORが旧契約で不足 | [補助標本](sample-catalog.md)から契約0.2.0へ拡張。旧契約の拒否テストも維持 |

道徳の項目 `82K04D0213000000` の親は `82K0400210000000`、外国語は教科見出し `82H02D…` から英語 `82H12D…`、理科は学年共通 `82602L…` から5年 `826025…` へ続きます。道徳の[当該項目](https://jp-cos.github.io/82K/04D0213000000)、外国語の[聞くこと](https://jp-cos.github.io/82H/12D2110000000)、理科の[振り子](https://jp-cos.github.io/826/0253121100000)についてLODの上位階層とも照合しています。原文と配布版の取得元は文科省CSVです。

選定した例では原文・階層・条件・複数観点・多対多の対応を保持しています。全教科に共通する親条件の継承規則や、全範囲の対象・目標整理の完了を確認したものではありません。

## 根拠の扱い

説明や判定観点は、まず学習指導要領の該当箇所と必要な親項目に対応させる。そこにない具体的主張は、文科省解説、大学・研究機関、著者と編集体制が明らかな学術教科書などで確認し、どの主張の根拠か記録する。初等教育の自明な定義や計算例に一律の引用を要求しない。

今回の教科横断の説明・条件・判定観点は選定した指導要領内に根拠がある。掲載順から学習前提を推測して追加していない。補助標本の大学・科学の概念には次を参照し、データの編集理由にも記録した。

- 理想気体の式と近似条件：OpenStax / Rice University, [University Physics Volume 2, §2.1](https://openstax.org/books/university-physics-volume-2/pages/2-1-molecular-model-of-an-ideal-gas)。低密度等の条件で実在気体を近似するモデルとして扱う根拠。
- 線形写像の定義：W. Keith Nicholson, [Linear Algebra with Applications, §2.6](https://math.libretexts.org/Bookshelves/Linear_Algebra/Linear_Algebra_with_Applications_%28Nicholson%29/02%3A_Matrix_Algebra/2.06%3A_Linear_Transformations)。加法とスカラー倍を保存する定義の根拠。

非告示資料の種類・書誌・取得情報は[契約0.2.0](exchange-contract-0.2.md)の `sources` で分けて表現する。元の補助例の参照記録は旧版とともに保持する。

## 検証方法

[Swiftテスト](../Tests/CurriculaTests/CrossSubjectSamplesTests.swift)でJSON往復、69原文と外部コードの完全一致、明示階層、学年差、条件、態度目標、多対多対応を確認する。親の教科を取り違えた入力、循環、参照先の欠落、部分対応の偽装も拒否されることを確認する。

[独立したPython読込](../scripts/check_contract.py)で選定表と公開JSONの階層・原文・対応を照合し、[HTTP APIテスト](../scripts/test_api.py)で取得と版の分離を確認する。`make check` は旧版・0.2.0標本・全原文版の再生成も確認する。初回の結果は[構造標本の記録](reviews/structure-samples.md)、0.2.0への拡張は[契約の記録](reviews/schema-0.2.0.md)を参照。
