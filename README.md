# Curricula

学習指導要領の原文、学ぶ対象、学習目標を結び、画面とAPIで利用するデータ基盤です。原文を読み、構造や根拠を確かめ、ローカルで独自の説明・目標・判定観点を編集できます。教科書・問題集の見え方を試す教材も収録しています。

小学校・中学校の原文収録は完了し、目標の整理を進めています。高校・大学教養への拡張は長期目標です。コードと同梱データは[GitHub](https://github.com/KantoYamamoto/Curricula)で公開しています。Webサイト・APIのインターネット配信は未実装で、公開範囲と設計は[Issue #2](https://github.com/KantoYamamoto/Curricula/issues/2)以降で検討中です。

## ローカルで使う

Python 3.10以上で閲覧できます。編集・データ生成・検証にはSwift 6.0以上も必要です。追加パッケージのインストールは不要です。リポジトリのルートで実行します。

```sh
make serve
```

| ページ | できること |
|---|---|
| [読む](http://127.0.0.1:8000/read) | 原文と整理した目標を目次に沿って読む |
| [構造を見る](http://127.0.0.1:8000/structure) | 原典階層、学年・教科、根拠、前提を確かめる |
| [収録状況](http://127.0.0.1:8000/coverage) | 原文収録と目標整理の進捗を別々に見る |
| [教材を見る](http://127.0.0.1:8000/learn) | 4単元・14問の教科書／問題集を試す |

終了はCtrl+C。別ポートを使う場合は `python3 scripts/serve.py --port 8001`。通常の起動・生成・テストでは原典サイトへアクセスしません。

編集する場合は閲覧サーバーを終了し、次を実行します。

```sh
make serve-edit
```

[編集ページ](http://127.0.0.1:8000/edit)では学ぶ対象・目標の作成、本文・条件・自然言語の判定観点の編集、原文への根拠追加、差分・履歴確認ができます。下書きは `.local/curricula.sqlite3` に残ります。確認した下書きから新しい不変のデータ版を作り、原文単位の整理進捗を記録します。[編集・保存・バックアップの手順](docs/local-editing.md)を参照してください。

## 収録内容

| データ | 現在の内容 |
|---|---|
| 小中の原文 `curriculum-0.3.0` | 小学校82V12の3,747項目、中学校83V11の2,190項目、両校の前文。計5,939項目 |
| 目標整理 `reading-0.3.1`（初期表示） | 原文を保持し、小学校国語1・2年「読むこと」の学ぶ対象6件・目標6件・判定注釈6件を追加 |
| 教科横断の構造標本 `cross-subject-0.2.0` | 8教科・11例。学年帯、実験条件、資料による考察、合奏、態度目標などを検証 |
| 編集・境界の標本 | UUIDを保つ修正、分割・統合、AND/OR前提、機関別経路、異なる定義、旧契約の互換性を検証 |
| 教材試作 | 国語1・2年の手順読解、国語3・4年の物語、算数3年のデータ整理、理科5年の振り子 |

原文は総則、全教科、道徳、活動、学年別漢字配当表を含みます。幼稚園・特別支援・高校や解説書の全範囲は含みません。138区切りの原文収録は完了していますが、目標整理の完了は0区切り、整理中は1区切りです。国語1・2年の原文62項目中12項目を確認済みで、次は「話すこと・聞くこと」です。[範囲と作業台帳](docs/curriculum-coverage.md)で続きを確認できます。

教材の選択・数値・順序問題は答え合わせ、記述問題は解答例と自然言語の観点を表示します。回答はページ内だけに保持し、再読み込みで消えます。教材は目標とは別データで、試作の追加を原文・目標の網羅完了とは数えません。[教材の操作と保存境界](docs/learning-preview.md)。

## 開発・データ利用

```sh
make check               # Swift・Python・契約・固定入力からの再現性を検証
make export              # Swiftの小標本を再生成（DBの編集内容は書き出さない）
make export-curriculum   # 固定した原典入力から原文版と台帳を再生成
```

読み取りAPIの例：

```sh
curl 'http://127.0.0.1:8000/api/v1/releases'
curl 'http://127.0.0.1:8000/api/v1/releases/reading-0.3.1/entities?kind=goal&stage=elementary&grade=1'
```

[画面とAPI](docs/viewer-api.md)、[交換契約0.2.0](docs/exchange-contract-0.2.md)、[開発の引き継ぎ](docs/implementation-brief.md)に仕様と変更手順があります。公開済みデータは保持し、変更は新しい版として追加します。編集起動時の0.2.0データはDBが保存元です。旧契約0.1.0と教材試作はJSONから読みます。

| 場所 | 役割 |
|---|---|
| `Sources/Curricula` | 共通モデル、検証、JSON出力 |
| `Sources/CurriculaPilot` / `Sources/CurriculaCLI` | 小標本・固定原典、生成・検証コマンド |
| `data/catalog` / `data/sources/mext` / `data/coverage.json` | 原文版、固定原典、原文の作業台帳 |
| `data/releases` / `data/authoring` / `data/work-reviews` | 小標本、整理した公開版、版付き進捗記録 |
| `data/learning-preview` | 教材・問題の試作データ |
| `scripts` / `web` | HTTP API、SQLite、取り込み、閲覧・編集画面 |
| `Tests/CurriculaTests` / `scripts/test_*.py` | モデル・保存・APIのテスト |
